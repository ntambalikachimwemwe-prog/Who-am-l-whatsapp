# Life Journey Game

The repository is being repurposed into **Life Journey**, a third-person open-world life simulation for Windows PC and Android.

The Godot 4 project is in [life-simulator/](life-simulator/). The original Social Hub app remains available on the `main` branch; this game work is isolated on `life-simulator-game`.

See [the game README](life-simulator/README.md) for setup, controls, current implementation and remaining production work.
