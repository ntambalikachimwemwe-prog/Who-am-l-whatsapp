# Character portrait assets

Add approved, cropped character portrait images here as PNG or JPG.

Expected optional filenames:
- player.png — main player character (the person selected by the user)
- friend.png
- girlfriend.png
- teacher.png
- classmate.png
- roommate.png
- football_friend.png
- lecturer.png
- colleague.png
- neighbour.png
- mother.png

Use original photos, crop out chat/status interface elements, and get permission from each identifiable friend before including their likeness. Keep portraits reasonably compressed for mobile performance. The game falls back to simple 2D drawings if an image is not present.
